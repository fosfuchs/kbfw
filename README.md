# kbfw

Утилита командной строки для чтения и записи прошивки контроллера клавиатуры (микросхема ITE) ноутбуков ASUS ROG из-под Linux, напрямую через hidraw. Реализует протокол официальной утилиты ASUS «ROG Keyboard Firmware Update», восстановленный из захваченного USB-трафика.

## Назначение

Контроллер клавиатуры ASUS ROG (ITE8252 и родственные) при сбое обновления прошивки или просадке питания может перейти в режим заводского загрузчика. Признаки: встроенная клавиатура не работает нигде, включая BIOS; в системе вместо рабочего устройства `0b05:19b6` (ASUSTek N-KEY Device) висит `048d:89db` (ITE Upgrade Mode). Программа позволяет без Windows и без официальной утилиты:

- прочитать прошивку контроллера целиком (дамп 0x40000 байт);
- выкачать прошивку из контроллера в виде образа штатного формата (`$INVENTEC`): готовый файл для резервной копии или повторной прошивки;
- записать в контроллер образ прошивки своей модели (`FGA00000.<модель>.<версия>` из пакета ASUS) с проверкой каждого сектора;
- сверить содержимое контроллера с образом.

После успешной записи выключайте ноутбук полностью и включайте заново: обычная перезагрузка не поможет.

## Проверено на

- ASUS ROG Strix G614PP, контроллер ITE8252, образ `FGA00000.G614PP.317` (SHA-256 `7ea3b725d62f533381c361fc6f9e5525215e742440f168a8ed933be8507fe611`, 261376 байт).
- Ремонт реального экземпляра выполнен этим протоколом в октябре 2026: контроллер был возвращён из Upgrade Mode в рабочее состояние, клавиатура работает.

Режим загрузчика в целом одинаков у ITE-контроллеров клавиатур (сторонняя утилита KbBurnUI поддерживает IT8252/IT8259/IT8258/IT8176FN/IT8295FN), но запись на других моделях не тестировалась.

## Требования

- Linux с hidraw;
- доступ к `/dev/hidraw*`
- контроллер в режиме загрузчика;
- образ прошивки своей модели.

## Сборка

    cargo build --release

Внешних зависимостей нет. Бинарник: `target/release/kbfw`.

## Использование

    kbfw test                     проверка связи: чтение адресов 0x000000 и 0x03FF00
    kbfw probe                    чтение по контрольным адресам карты чипа
    kbfw read 0x3C000 0x400       чтение блоками по 56 байт
    kbfw dump kbfw-dump.bin       полный дамп 0x40000 байт
    kbfw pull [файл]              выкачка прошивки в формате FGA (шапка $INVENTEC)
    kbfw flash <образ> [ключи]    запись отличающихся секторов
    kbfw verify <образ>           сверка чипа с образом

Ключи `flash`: `--dry` (только показать список секторов), `--only 0x11000,0x11400` (задать сектора вручную), `--factory` (включить хвостовую зону 0x3C000-0x3F800).

По умолчанию `flash` перебирает код-регион 0x0-0x3BFFF, сравнивает чип с образом и пишет только отличающиеся сектора (карта: байт чипа по адресу X соответствует `образ[X+0x100]`), проверяя каждый сектор чтением после записи, до 4 попыток на сектор. Неудавшиеся сектора выводятся на экран и сохраняются в `kbfw-still.txt`. `verify` возвращает код 1, если есть расхождения; `flash` возвращает 1, если что-то не записалось.

`pull` читает чип целиком и сохраняет образ в штатном формате FGA (0x3FD00 байт): шапка `$INVENTEC` + содержимое чипа от 0x0 до 0x3FBFF. Имя модели для шапки берётся из метаданных чипа (строка вида `FGA00000.<модель>.<версия>` в зоне 0x3C000), при необходимости задаётся ключом `--model`. Файл прошивается обратно командой `flash` и совместим с официальной утилитой ASUS. Сырой дамп без шапки, включая хвост чипа вне карты образа, даёт команда `dump`.

Полный цикл восстановления:

    kbfw pull backup-fw.bin
    kbfw dump old.bin
    kbfw flash downloaded-fw.bin
    # полностью выключить ноутбук, подождать 30-60 секунд, включить
    lsusb | grep 19b6

## Предостережения

- Заливать только образ своей модели: прошивка от другой модели может окончательно вывести контроллер из строя.
- Не прерывать питание во время записи.
- Программа работает, только когда контроллер находится в режиме 048d:89db. Пока клавиатура работает (0b05:19b6), прошивать нечего, и запускать что-либо не нужно.
- В режиме загрузчика клавиатура не работает по определению; подсветка клавиатуры (Aura, устройство 19b6) в этом состоянии тоже недоступна.
